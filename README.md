# 作业清 · 学生作业管理

这是基于 Supabase 的云端作业管理网页。它覆盖邮箱登录、班级协作、作业登记、个性化评价、班级反馈、个人档案和全班热力图，并针对手机与讲台大屏做了适配。

## 打开方式

双击 `index.html`，或右键选择“打开方式 → Microsoft Edge”。

云端数据保存在 Supabase PostgreSQL 中，通过 RLS 控制不同教师可以访问的班级和可执行的操作。

在 HTTPS 网站中首次打开后，可以安装到手机主屏。离线时可加载应用外壳，但登录和云端数据同步需要网络。

完整部署步骤见 [SUPABASE_SETUP.md](./SUPABASE_SETUP.md)。

## 已实现功能

- 今日总览：本次作业过关率、班级人数、待订正、未提交和评价使用量。
- 作业登记：学生卡片点选、四种作业状态、奖励/扣分标签、教师备注。
- 批量登记：支持多选学生、连续选择多个小组，并统一设置作业状态。
- 个人批量修改：在单个学生档案中可多选多项作业并统一更改状态。
- 展示模式：学生卡片与画像可切换姓名、学号或两者；反馈可选择姓名、学号或仅人数。
- 作业管理：新建、编辑、删除作业，并从左侧历史列表快速切换。
- 班级反馈：根据登记结果自动生成文案，可选是否展示姓名、待订正名单和个性化标签。
- 学生画像：全班热力图、近六次作业趋势、优先跟进名单和评价积分榜。
- 个人档案：作业轨迹、过关/订正/未提交统计、评价标签与当前备注。
- 评价设置：自定义标签与分值、班级信息、学生名单管理。
- 班级号：创建班级后自动生成不可手动编辑的 8 位随机数字。
- 数据安全：Supabase 账号登录、数据库 RLS、当前班级 JSON 导出、修改人记录和投屏隐藏姓名。
- 登录保持：会话保存在当前浏览器，token 在后台自动刷新，不会因切换标签页重复进入加载页。
- 批量管理：批量添加、删除学生，创建小组并批量分配；支持“学号 + 姓名”或“姓名 + 学号”，未填写学号时自动顺序编号。
- 响应式布局：支持电脑、平板、手机和讲台大屏。

## 数据说明

首次登录后是空白工作台，不会生成示例班级、学生或作业。请先创建自己的班级，再通过“管理学生名单”批量导入实际学生，最后创建第一项作业。

换设备时直接使用同一邮箱登录即可。协作者则使用自己的账号和班级号加入同一班级。

注意：`file://` 本地文件和 `https://` 线上网站属于不同浏览器存储区域，需要分别登录一次。
